# Contact Management System
The Contact Management System is a simple yet efficient Java-based application that helps users manage their personal or professional contacts.
It allows adding, viewing, searching, updating, and deleting contact records — all through an easy-to-use console or GUI interface.
Features
 Contact Operations

 Add New Contact — store name, phone number, email, and address

 Search Contact — search by name or phone number

 View All Contacts — display all saved contacts in a clean format

 Update Contact — modify existing contact information

 Delete Contact — remove a contact from the list or database

 Data Storage

File handling or JDBC (Java Database Connectivity) for persistent storage

Supports MySQL or PostgreSQL (if database version is used)

 Additional Features

Input validation (valid name, number, and email format)

Simple text-based UI or basic Swing GUI (if implemented)

Fast and lightweight — runs on any system with Java installed
